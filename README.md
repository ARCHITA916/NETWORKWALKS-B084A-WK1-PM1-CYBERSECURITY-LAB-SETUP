# Kali Linux Virtual Lab – Initial Setup

## 1. Project Introduction

This project is part of my cybersecurity learning journey. I created a virtual lab using Oracle VirtualBox and Kali Linux to understand how virtual machines work and how their network settings can be configured.

The main aim is to build a separate lab environment where I can learn Linux fundamentals, networking concepts and basic cybersecurity practices through practical experience.

## 2. Project Goals

The project focuses on the following tasks:

- Setting up Oracle VirtualBox on Windows 11.
- Preparing and importing the Kali Linux virtual machine.
- Creating a dedicated NAT Network.
- Configuring Kali Linux network settings.
- Setting up a consistent IPv4 address.
- Checking internet access and DNS functionality.
- Creating a snapshot as a recovery point.
- Maintaining screenshots and setup documentation.

## 4. Implementation Process

### Step 1 – Preparing the Environment

Installed Oracle VirtualBox and 7-Zip on my Windows 11 system. These tools are used to manage virtual machines and prepare the Kali Linux installation files.

### Step 2 – Kali Linux Installation

Downloaded and extracted the Kali Linux virtual machine package and imported it into VirtualBox. Checked the initial virtual machine settings before starting it.

### Step 3 – Virtual Network Configuration

Prepared a dedicated NAT Network in VirtualBox for the lab environment.

This network configuration provides a way for virtual machines on the same network to communicate while accessing external networks through NAT.

### Step 4 – Network Setup in Kali Linux

Worked on configuring the Kali Linux network adapter and IPv4 settings. The objective is to maintain a consistent network configuration for future lab activities.
